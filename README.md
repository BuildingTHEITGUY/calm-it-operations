# 🌱 Calm IT Operations
### A Human-Centric IT Operations Playbook for Sustainable, World-Class Delivery

![License](https://img.shields.io/badge/license-MIT-green) ![Status](https://img.shields.io/badge/status-active-blue)

## Why This Repository Exists
Most IT Operations knowledge is learned the hard way:
* Through burnout
* Through internal politics
* Through late-night incidents
* Through audits driven by fear, not clarity

This repository exists to offer a **calm, practical alternative**. It captures real operational practices used in universities and mid-sized organizations to run reliable services without hero culture.

## 🚀 How to Use
1.  **Fork** this repository (Top right corner).
2.  Navigate to `02-THE-PLAYBOOK/01-annual-closure`.
3.  Download the **Excel Template**.
4.  Use it to capture your team's "Hidden Work" (Non-ITSM tickets).

## Core Philosophy
1.  **Stability is the Feature:** Boring is good.
2.  **People are not Consumables:** If it requires a hero, the system is broken.
3.  **Visibility Kills Politics:** Track the hidden work to prove value.
